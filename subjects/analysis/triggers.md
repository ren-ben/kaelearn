# Triggers: analysis

You see this, you reach for that. Grown by folios and debriefs; the source is in brackets.

- **An inequality between squares** → pass to $|x|,|y|$; $t\mapsto t^2$ is strictly increasing on $[0,\infty)$. (UE01/2)
- **Prove $A\le B$** → write $B-A$ as a square, or a sum of squares. (UE01/2)
- **Compare sets given by inequalities** → for every $\subset$ you see, write the inequality that proves it, and a point in the difference. (UE01/3)
- **Show two sets are equal** → arbitrary $x$, chain $\Leftrightarrow$ on membership, then "$x$ was arbitrary". (UE01/4)
- **A preimage of $\cup$, $\cap$ or a complement** → translate into $\vee$, $\wedge$, $\neg$. (UE01/4)
- **Is $f$ surjective?** → solve $f(a)=b$; list every condition the formula needs; check $a$ is in the domain. (UE01/5)
- **Strictly monotone** → injective; the inverse exists on the image and is monotone the same way. (UE01/6)
- **You solved an equation by $\Rightarrow$ steps** → only candidates so far: plug them back in. (UE01/7)
- **Refute an implication** → one point where the premise holds and the conclusion fails. (UE01/7)
- **An induction step for a closed formula** → factor out what the target contains. (UE01/8)
